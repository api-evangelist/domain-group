# Domain Group

> Domain Group (Domain Holdings Australia Ltd, trading as domain.com.au) is one half of
> Australia's residential property portal duopoly, alongside REA Group's realestate.com.au,
> and since 27 August 2025 a wholly owned subsidiary of CoStar Group. Domain runs a genuine
> self-serve public developer portal at developer.domain.com.au and publishes three
> machine-readable OpenAPI 3.0.4 documents covering agency, agent, listing, property,
> valuation, market-statistics and webhook surfaces, all served from api.domain.com.au
> behind API-key or OAuth 2.0 credentials.

Generated by API Evangelist on 2026-07-26. Domain publishes no llms.txt of its own
(https://developer.domain.com.au/llms.txt returns 404); this file is generated from
apis.yml and the artifacts in this repository.

Access model: sign up with GitHub, Google, or email and create a project. Two API packages
are granted immediately — Agents & Listings, and Properties & Locations. The other eleven
(Address Suggestions, Campaign reporting, Campaign preview, Listings Management,
Price Estimation, Property Enrichment, Property Package, PropertyRadar, Rental AVM,
Schools Data, Webhooks) are added per project and negotiated with an account manager.
Write access to listings is broker-gated: sandbox sign-off by email to api@domain.com.au
plus written permission from the principal agent of each agency.

## APIs

- [Address Suggestions](https://developer.domain.com.au/docs/latest/apis/pkg_address_suggestion): resolve free-text Australian addresses to Domain property ids.
- [Agents & Listings](https://developer.domain.com.au/docs/latest/apis/pkg_agents_listings): agencies, agents, residential/commercial/business/project listings, enquiries. Granted on signup.
- [Properties & Locations](https://developer.domain.com.au/docs/latest/apis/pkg_properties_locations): property records, location profiles, auction and sales results, suburb performance and demographics. Granted on signup.
- [Price Estimation](https://developer.domain.com.au/docs/latest/apis/pkg_price_estimation): automated sale price estimate with lower/mid/upper band and confidence.
- [Rental AVM](https://developer.domain.com.au/docs/latest/apis/pkg_rental_avm): automated rental estimates.
- [Property Enrichment](https://developer.domain.com.au/docs/latest/apis/pkg_property_enrichment): extra Domain-held property detail, features, zoning and perils.
- [Property Package](https://developer.domain.com.au/docs/latest/apis/pkg_property): bundled comprehensive property coverage.
- [PropertyRadar](https://developer.domain.com.au/docs/latest/apis/pkg_propertyradar): watchlist portfolios of properties, including G-NAF address lookup.
- [Schools Data](https://developer.domain.com.au/docs/latest/apis/pkg_schools_data): Australian schools by id or by latitude/longitude.
- [Listings Management](https://developer.domain.com.au/docs/latest/apis/pkg_listing_management): the CRM upload surface — create and update listings, read enquiries and processing reports. Broker-authorised.
- [Campaign API](https://developer.domain.com.au/docs/latest/apis/pkg_campaign_api): advertising campaign performance for listings and projects. Media agencies only.
- [Campaign API Preview](https://developer.domain.com.au/docs/latest/apis/pkg_campaign_api_preview): early-access channel of the Campaign API.
- [Webhooks](https://developer.domain.com.au/docs/latest/apis/pkg_webhooks): push notifications for agency, agent, enquiry, listing, project and listing-processing-report changes, plus a heartbeat.

## Notes for agents

- Everything is JSON over HTTPS, camelCase, except OAuth/OIDC requests which are snake_case.
- Read endpoints with many optional parameters are POST, not GET, to avoid URI length limits.
- There is NO idempotency key. Write retries are not idempotent by contract; the listing
  upserts are keyed on your own agency reference, so retry the same reference, never a new one.
- No public status page (the Atlassian Statuspage for Domain is inactive), no dated changelog,
  no CLI, no embedded UI components, no GraphQL, no gRPC, and no MCP server.
- No RESO Web API or Data Dictionary certification, no OData $metadata, no MLS/IDX surface,
  and no Universal Property Identifier. RESO is a North American standard with no presence in
  the Australian portal duopoly. Properties carry opaque Domain ids; PropertyRadar also
  accepts the Australian G-NAF address identifier.
- All data is licensed under the Domain Group API Terms and Conditions. Attribution is required.
